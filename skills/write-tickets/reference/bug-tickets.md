# Bug tickets

- Steps to reproduce come first, as the most important part. Each step says what the user did and meant to do.
- Then the actual result and the expected result, precisely.
- Facts stay apart from guesses. A suspected cause gets its own line, marked as a guess.
- The environment comes next, with the OS, the version or build, and whether other platforms show it.
- From a report, the evidence is copied (command, output, `file:line`), never paraphrased.
